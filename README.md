# CodeAlpha E-Commerce Store

Simple full-stack E-Commerce web application built for the **CodeAlpha Full Stack Development Internship**.

## Features
- User registration and login APIs (`/api/register`, `/api/login`)
- Product listing and single product details (`/api/products`, `/api/products/:id`)
- Shopping cart add, view, and remove (`/api/cart`)
- Order placement and order history (`/api/orders`)
- Responsive frontend using HTML, CSS, and Vanilla JavaScript

## Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3, JavaScript
